# ESS development preview (staging)

Unlisted development website for Endicott Speed Shop: https://caseycorean.github.io/ess-staging/

- Not the live site (that is https://endicottspeedshop.com/). Contents may be incomplete, unaccepted or wrong.
- Every page is marked `noindex,nofollow`; robots.txt disallows crawling; there is no sitemap and no analytics.
- `VERSION.json` names the exact website commit each version was built from. Each commit here is one staged version, tagged `v-<website commit>`; earlier versions can be restored.
- Built files only. Source and process live elsewhere.
